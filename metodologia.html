Construção

Metodologia.

Como o grafo foi construído: dos vértices às arestas, dos dados teóricos à interface de exploração.

Levantamento teórico

Pesquisa em fontes primárias e secundárias da Epistemologia da Ciência, com foco em autores que propuseram critérios explícitos de demarcação. A bibliografia completa está em Bibliografia.

Definição dos vértices

Dois tipos de vértices foram modelados:

  • Filósofos da ciência (círculos brancos): cada autor que formulou uma definição de ciência.
  • Campos com pretensão de cientificidade (círculos pretos): cada disciplina ou prática candidata.

Definição das arestas

Também dois tipos:

  • Autor → Campo: verde se o autor considera ciência; vermelho se considera pseudociência.
  • Autor → Autor: linha tracejada, indicando influência ou diálogo entre definições. Para visualizar, selecione o filtro "Autores"

Implementação web customizada

O grafo foi construído inteiramente com tecnologias web nativas (HTML, CSS e JavaScript), consumindo as informações da nossa base de dados de autores e campos dinamicamente a partir de arquivos JSON. Para garantir melhor performance e fluidez visual, adotamos uma arquitetura de renderização híbrida: utilizamos o Canvas para processar os rastros de luz dinâmicos e os efeitos visuais, enquanto uma camada invisível em SVG é sobreposta para detectar com precisão as interações do mouse.

Subgrafos navegáveis

Em vez de exibir o grafo completo de uma só vez, o usuário pode filtrar por filósofo, por campo, ou por classificação. Cada subgrafo conta uma história mais legível do que o todo.

Integração com a web

O grafo é embutido neste site. A interface inclui legenda, filtros, e textos contextuais que conectam a visualização aos conceitos da Epistemologia.

Inspirações

O projeto se apoia em referências contemporâneas de visualização de conhecimento, incluindo Places & Spaces: Mapping Science (com destaque para o trabalho Science Paths de Kim Albrecht, Barabási e Sinatra) e as visualizações narrativas da publicação The Pudding.
